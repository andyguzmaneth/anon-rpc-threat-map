Experiments / anon-RPC

anon-RPC threat map

Who can learn what about a wallet user when its RPC traffic goes through anon-RPC, by adversary and by the anonymity network plugged into it. anon-RPC is a socket: Tor, Nym and Nox workers exist, and each gives different protection. Hiding from the RPC provider is one adversary. This page maps the others, and gives a method to rate any network that plugs in.

Draft v0.2 Spec checked: anon-rpc 0.3.2 (2026-09-25) Networks: Tor, Nym, Nox
